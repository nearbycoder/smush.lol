01

Quick start

All requests use the production base URL.

Base URL https://smush.lol
Authentication

There is no API key or account. Send a request and the transformed image is returned as the response body.

02

Transform a remote image

Use a public HTTP(S) image as the source.

GET /api/image

url is required. Add any transform parameters to the same query string. The response is inline and can be used directly in an image element.

HTML
<img
  src="https://smush.lol/api/image?url=https%3A%2F%2Fexample.com%2Fphoto.jpg&width=800&format=webp&quality=82"
  alt=""
/>
JavaScript
const image = new URL("https://smush.lol/api/image");
image.searchParams.set("url", "https://example.com/photo.jpg");
image.searchParams.set("width", "800");
image.searchParams.set("format", "webp");
image.searchParams.set("quality", "82");

document.querySelector("img").src = image.toString();
Remote response caching

Remote transformations return Cache-Control: public, max-age=3600, stale-while-revalidate=86400.

03

Transform an upload

Send a multipart form with an image file.

POST /api/smush
cURL
curl https://smush.lol/api/smush \
  -F "image=@photo.jpg" \
  -F "width=800" \
  -F "format=webp" \
  -F "quality=82" \
  --output photo-smushed.webp
JavaScript
const body = new FormData();
body.set("image", file);
body.set("width", "800");
body.set("format", "webp");
body.set("quality", "82");

const response = await fetch("https://smush.lol/api/smush", {
  method: "POST",
  body,
});

const result = await response.blob();
Upload responses

Uploads use Content-Disposition: attachment and Cache-Control: no-store.

06

Errors

Errors are returned as JSON with an error message.

JSON
{ "error": "The URL did not return an image." }
400Missing or malformed input
403Private or blocked source URL
413Source or output is too large
415Remote response is not an image
422Image decode or transform failed
502Remote host failed, timed out, or redirected too often
07

Limits & safety

Requests are bounded to keep the public API predictable.

  • 15 MBMaximum upload or remote source size
  • 48 MPMaximum decoded image and output area
  • 12,000 pxMaximum width or height
  • 10 secondsRemote source timeout
  • 3 redirectsEach destination is validated again
Remote source rules

Only public HTTP(S) URLs on standard web ports are accepted. Credentials, localhost, private networks, and non-web protocols are blocked. Images are processed in memory and are not stored by the application.
